# Space Medicine Clinical Trials Tracker

Goal: map registered clinical studies related to spaceflight, microgravity and astronaut health.

## Steps
1. Go to [ClinicalTrials.gov](https://clinicaltrials.gov/).
2. Search terms to try: `spaceflight`, `microgravity`, `astronaut`, `bed rest`, `space medicine`.
3. Download results as CSV and save in this folder as `trials.csv`.
4. Clean and summarise in a notebook: count by status, phase, condition and country.
5. Write a short summary of research gaps (for example, how few studies target infection or microbiome).

## Columns worth keeping
NCT Number, Study Title, Status, Conditions, Interventions, Phase, Start Date, Locations.

> Only use publicly available data and cite the access date.
